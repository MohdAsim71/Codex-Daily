# 🤝 Contributing

This is a personal learning journal. Here's how you can help:

## Found an error?
Open an **Issue** with the label `correction` and describe what's wrong.

## Want to suggest a topic?
Open an **Issue** with the label `topic-request`.

## Want to improve formatting or fix a typo?
Open a **Pull Request** — small fixes are always welcome!

## Inspired to start your own?
Fork this repo, clear the entries, and make it yours. Drop a link — I'd love to follow your journey!

---
*Please be respectful and constructive. This is a learning space.*
