## 👋 What is this?

This is my **public learning journal** — a repository where I document everything I learn as a developer, day by day.

No curated highlights. No polished course notes. Just raw, consistent, honest learning in public — covering Android development, AI/ML, data structures and algorithms, system design, and the everyday craft of building software.

> *"The best time to start documenting your learning was yesterday. The second best time is today."*

If you're here, you're welcome to read, borrow ideas, suggest improvements, or start your own version of this.
