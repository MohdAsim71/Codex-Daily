# 5.4 — Streaming Token Output in Android UI (Kotlin Flow)

> **Module 5 · Lesson 4**

## 🎯 Learning Objectives

By the end of this lesson you will be able to:

- Stream LLM tokens to a `TextView` or `RecyclerView` in real-time
- Build a typewriter animation effect for generated text
- Cancel an in-progress generation cleanly
- Handle backpressure when tokens arrive faster than UI can update
- Show a typing indicator while the model is generating

---

## 1. Why Streaming Matters for LLM UX

```
WITHOUT streaming:
  User sends message
  App shows spinner for 8–15 seconds
  Full response appears all at once
  → Feels slow and unresponsive

WITH streaming:
  User sends message
  First token appears in ~200ms
  Words stream in at 20 tok/s
  Response builds up naturally
  → Feels fast and engaging (like ChatGPT)
```

Streaming is not optional — it's the difference between a good and bad LLM app UX.

---

## 2. The Token Flow Architecture

```
LLM Engine (background thread)
  │  emits String tokens via callback
  ▼
Channel<String> (buffer)
  │  converts callback to Flow
  ▼
StateFlow<String> (ViewModel)
  │  accumulates tokens into full response
  ▼
UI Layer (main thread)
  │  collects StateFlow and updates TextView
  ▼
User sees text streaming in real-time
```

## 3. ViewModel — Managing the Stream

```kotlin
// ChatViewModel.kt
package com.yourname.chatapp

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import kotlinx.coroutines.*
import kotlinx.coroutines.flow.*

// Represents one message in the chat
data class ChatMessage(
    val id: Long = System.currentTimeMillis(),
    val role: String,          // "user" or "assistant"
    val content: String,
    val isStreaming: Boolean = false   // true while tokens are arriving
)

// All possible UI states
data class ChatUiState(
    val messages: List<ChatMessage> = emptyList(),
    val isGenerating: Boolean = false,
    val streamingText: String = "",    // live token accumulation
    val tokensPerSec: Float = 0f,
    val error: String? = null
)

class ChatViewModel(
    private val llmEngine: GemmaInferenceHelper   // or MlcLlmEngine
) : ViewModel() {

    private val _uiState = MutableStateFlow(ChatUiState())
    val uiState: StateFlow<ChatUiState> = _uiState.asStateFlow()

    // Active generation job — kept so we can cancel it
    private var generationJob: Job? = null

    fun sendMessage(userText: String) {
        if (_uiState.value.isGenerating) return   // prevent double-send
        if (userText.isBlank()) return

        // Add user message to history
        val userMsg = ChatMessage(role = "user", content = userText)
        _uiState.update { it.copy(
            messages     = it.messages + userMsg,
            isGenerating = true,
            streamingText = "",
            error        = null
        )}

        generationJob = viewModelScope.launch {

            val sb         = StringBuilder()
            val startTime  = System.currentTimeMillis()
            var tokenCount = 0

            try {
                // Get streaming flow from LLM engine
                val tokenFlow = llmEngine.generateResponseStream(userText)

                tokenFlow.collect { token ->
                    sb.append(token)
                    tokenCount++

                    // Calculate tok/s
                    val elapsedSec = (System.currentTimeMillis() - startTime) / 1000f
                    val tokPerSec  = if (elapsedSec > 0) tokenCount / elapsedSec else 0f

                    // Update streaming text on every token
                    _uiState.update { it.copy(
                        streamingText = sb.toString(),
                        tokensPerSec  = tokPerSec
                    )}
                }

                // Generation complete — move streaming text to message list
                val assistantMsg = ChatMessage(
                    role    = "assistant",
                    content = sb.toString(),
                    isStreaming = false
                )
                _uiState.update { it.copy(
                    messages      = it.messages + assistantMsg,
                    isGenerating  = false,
                    streamingText = ""
                )}

            } catch (e: CancellationException) {
                // User cancelled — save partial response if any
                if (sb.isNotEmpty()) {
                    val partial = ChatMessage(
                        role    = "assistant",
                        content = sb.toString() + " ✋ [stopped]",
                        isStreaming = false
                    )
                    _uiState.update { it.copy(
                        messages      = it.messages + partial,
                        isGenerating  = false,
                        streamingText = ""
                    )}
                } else {
                    _uiState.update { it.copy(isGenerating = false, streamingText = "") }
                }

            } catch (e: Exception) {
                _uiState.update { it.copy(
                    isGenerating  = false,
                    streamingText = "",
                    error         = "Generation failed: ${e.message}"
                )}
            }
        }
    }

    /** Stop the current generation mid-stream */
    fun stopGeneration() {
        generationJob?.cancel()
        generationJob = null
    }

    fun clearChat() {
        stopGeneration()
        _uiState.value = ChatUiState()
    }

    override fun onCleared() {
        super.onCleared()
        generationJob?.cancel()
    }
}
```

## 4. StreamingTextView — Custom View with Typewriter Effect

For a polished streaming experience, use a custom view that animates new tokens:

```kotlin
// StreamingTextView.kt
package com.yourname.chatapp.ui

import android.content.Context
import android.util.AttributeSet
import androidx.appcompat.widget.AppCompatTextView
import kotlinx.coroutines.*

/**
 * A TextView that smoothly animates new text being appended.
 * Creates a typewriter effect as tokens stream in.
 */
class StreamingTextView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null
) : AppCompatTextView(context, attrs) {

    private var displayedLength = 0
    private var fullText = ""
    private var animJob: Job? = null

    /**
     * Update with new streaming text.
     * Only the newly added characters are animated.
     */
    fun updateStreamingText(newText: String) {
        if (newText.length <= displayedLength) {
            // Reset (e.g. new conversation started)
            displayedLength = 0
            fullText = newText
            text = newText
            return
        }

        fullText = newText
        animateNewCharacters()
    }

    private fun animateNewCharacters() {
        animJob?.cancel()
        animJob = CoroutineScope(Dispatchers.Main).launch {
            while (displayedLength < fullText.length) {
                // Show one more character
                displayedLength++
                text = fullText.substring(0, displayedLength)

                // Small delay between characters for typewriter feel
                // Faster for longer texts so it doesn't fall too far behind
                val delay = when {
                    fullText.length - displayedLength > 100 -> 5L   // fast catch-up
                    fullText.length - displayedLength > 20  -> 10L  // normal
                    else                                    -> 15L  // slow for last chars
                }
                delay(delay)
            }
        }
    }

    /** Show full text immediately (no animation) */
    fun setFinalText(text: String) {
        animJob?.cancel()
        displayedLength = text.length
        fullText = text
        this.text = text
    }

    fun clearText() {
        animJob?.cancel()
        displayedLength = 0
        fullText = ""
        text = ""
    }

    override fun onDetachedFromWindow() {
        super.onDetachedFromWindow()
        animJob?.cancel()
    }
}
```

## 5. TypingIndicator — Show While Model Thinks

```kotlin
// TypingIndicatorView.kt
package com.yourname.chatapp.ui

import android.animation.ValueAnimator
import android.content.Context
import android.util.AttributeSet
import android.view.animation.LinearInterpolator
import androidx.appcompat.widget.AppCompatTextView

/**
 * Animated "●●●" typing indicator shown while LLM generates.
 */
class TypingIndicatorView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null
) : AppCompatTextView(context, attrs) {

    private val dots = listOf("●", "● ●", "● ● ●")
    private var dotIndex = 0
    private var animator: ValueAnimator? = null

    fun startAnimation() {
        visibility = android.view.View.VISIBLE
        animator = ValueAnimator.ofInt(0, 2).apply {
            duration       = 900L
            repeatMode     = ValueAnimator.RESTART
            repeatCount    = ValueAnimator.INFINITE
            interpolator   = LinearInterpolator()
            addUpdateListener { anim ->
                dotIndex = anim.animatedValue as Int
                text = dots[dotIndex]
            }
            start()
        }
    }

    fun stopAnimation() {
        animator?.cancel()
        visibility = android.view.View.GONE
        text = ""
    }
}
```

## 6. Chat RecyclerView Adapter

```kotlin
// ChatAdapter.kt
package com.yourname.chatapp.ui

import android.view.*
import android.widget.TextView
import androidx.recyclerview.widget.DiffUtil
import androidx.recyclerview.widget.ListAdapter
import androidx.recyclerview.widget.RecyclerView
import com.yourname.chatapp.ChatMessage
import com.yourname.chatapp.R

class ChatAdapter : ListAdapter<ChatMessage, ChatAdapter.ViewHolder>(DIFF_CALLBACK) {

    companion object {
        private const val VIEW_TYPE_USER      = 0
        private const val VIEW_TYPE_ASSISTANT = 1

        private val DIFF_CALLBACK = object : DiffUtil.ItemCallback<ChatMessage>() {
            override fun areItemsTheSame(a: ChatMessage, b: ChatMessage) = a.id == b.id
            override fun areContentsTheSame(a: ChatMessage, b: ChatMessage) = a == b
        }
    }

    inner class ViewHolder(view: View, val viewType: Int) : RecyclerView.ViewHolder(view) {
        val tvContent: StreamingTextView = view.findViewById(R.id.tvContent)
        val tvMeta: TextView?            = view.findViewById(R.id.tvMeta)
    }

    override fun getItemViewType(position: Int): Int {
        return if (getItem(position).role == "user") VIEW_TYPE_USER
               else VIEW_TYPE_ASSISTANT
    }

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): ViewHolder {
        val layout = if (viewType == VIEW_TYPE_USER)
            R.layout.item_chat_user
        else
            R.layout.item_chat_assistant

        val view = LayoutInflater.from(parent.context).inflate(layout, parent, false)
        return ViewHolder(view, viewType)
    }

    override fun onBindViewHolder(holder: ViewHolder, position: Int) {
        val message = getItem(position)

        if (message.isStreaming) {
            // Live streaming message — text arrives via updateStreamingText()
            holder.tvContent.updateStreamingText(message.content)
        } else {
            // Completed message — show immediately
            holder.tvContent.setFinalText(message.content)
        }

        holder.tvMeta?.text = if (message.role == "assistant") "🤖 Gemma 2B" else ""
    }
}
```

## 8. Activity — Collecting the StateFlow

```kotlin
// ChatActivity.kt
class ChatActivity : AppCompatActivity() {

    private val viewModel: ChatViewModel by viewModels()
    private lateinit var adapter: ChatAdapter
    private lateinit var recyclerView: RecyclerView
    private lateinit var etInput: EditText
    private lateinit var btnSend: ImageButton
    private lateinit var btnStop: ImageButton
    private lateinit var typingIndicator: TypingIndicatorView
    private lateinit var tvStats: TextView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_chat)

        setupViews()
        observeUiState()
    }

    private fun setupViews() {
        adapter       = ChatAdapter()
        recyclerView  = findViewById(R.id.recyclerView)
        etInput       = findViewById(R.id.etInput)
        btnSend       = findViewById(R.id.btnSend)
        btnStop       = findViewById(R.id.btnStop)
        typingIndicator = findViewById(R.id.typingIndicator)
        tvStats       = findViewById(R.id.tvStats)

        recyclerView.apply {
            layoutManager = LinearLayoutManager(this@ChatActivity).apply {
                stackFromEnd = true   // new messages appear at bottom
            }
            adapter = this@ChatActivity.adapter
        }

        btnSend.setOnClickListener {
            val text = etInput.text.toString().trim()
            if (text.isNotEmpty()) {
                viewModel.sendMessage(text)
                etInput.text.clear()
            }
        }

        btnStop.setOnClickListener {
            viewModel.stopGeneration()
        }
    }

    private fun observeUiState() {
        lifecycleScope.launch {
            viewModel.uiState
                .flowWithLifecycle(lifecycle, Lifecycle.State.STARTED)
                .collect { state ->
                    updateMessages(state)
                    updateControls(state)
                }
        }
    }

    private fun updateMessages(state: ChatUiState) {
        val displayMessages = state.messages.toMutableList()

        // Append streaming message as a virtual entry
        if (state.isGenerating && state.streamingText.isNotEmpty()) {
            displayMessages.add(
                ChatMessage(
                    id          = -1L,   // temp ID
                    role        = "assistant",
                    content     = state.streamingText,
                    isStreaming = true
                )
            )
        }

        adapter.submitList(displayMessages.toList()) {
            // Scroll to bottom after list updates
            if (displayMessages.isNotEmpty()) {
                recyclerView.smoothScrollToPosition(displayMessages.size - 1)
            }
        }
    }

    private fun updateControls(state: ChatUiState) {
        // Show/hide typing indicator
        if (state.isGenerating && state.streamingText.isEmpty()) {
            typingIndicator.startAnimation()  // waiting for first token
        } else {
            typingIndicator.stopAnimation()
        }

        // Show/hide Stop button
        btnStop.visibility = if (state.isGenerating) View.VISIBLE else View.GONE
        btnSend.visibility = if (state.isGenerating) View.GONE else View.VISIBLE

        // Disable input while generating
        etInput.isEnabled = !state.isGenerating

        // Show performance stats
        if (state.tokensPerSec > 0) {
            tvStats.text = "${"%.1f".format(state.tokensPerSec)} tok/s"
            tvStats.visibility = View.VISIBLE
        } else {
            tvStats.visibility = View.GONE
        }

        // Show errors
        state.error?.let { error ->
            android.widget.Toast.makeText(this, error, android.widget.Toast.LENGTH_SHORT).show()
        }
    }
}
```

## 9. Backpressure — Tokens Faster Than UI

If the model generates faster than the UI can redraw (rare but possible):

```kotlin
// Throttle UI updates to max 30fps using conflation
// In ViewModel — replace direct update with conflated channel
private val _streamingText = MutableStateFlow("")

// Collect with throttle in Activity
lifecycleScope.launch {
    viewModel.uiState
        .map { it.streamingText }
        .distinctUntilChanged()    // only emit when text changes
        .collect { text ->
            streamingTextView.updateStreamingText(text)
        }
}

// OR — use sample() to limit update frequency
viewModel.uiState
    .map { it.streamingText }
    .sample(33)                   // max ~30fps updates
    .collect { text ->
        streamingTextView.updateStreamingText(text)
    }
```

## 10. Summary

- Keep generation job in ViewModel — cancel it from `stopGeneration()`
- Use `Channel<String>` to bridge LLM callbacks to `Flow`
- `StateFlow<ChatUiState>` holds ALL UI state — one source of truth
- Append streaming text as a temporary list item — remove when done
- `TypingIndicatorView` fills the gap between send and first token
- `StreamingTextView` animates new characters for smooth typewriter effect
- `distinctUntilChanged()` + `sample(33)` prevent excessive UI redraws
