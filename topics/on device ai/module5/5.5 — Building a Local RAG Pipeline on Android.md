## 1. What is RAG and Why Use It On-Device?

```
The LLM Knowledge Problem:
  Gemma 2B was trained on data up to a certain date.
  It knows nothing about:
    ❌ Your personal notes
    ❌ Your company's internal documents
    ❌ Recent events
    ❌ Any data specific to your app's users

RAG (Retrieval-Augmented Generation) solves this:

  User Question
       │
       ▼
  [1. RETRIEVE] Search your document store for relevant chunks
       │
       ▼
  [2. AUGMENT]  Add retrieved chunks to the LLM prompt as context
       │
       ▼
  [3. GENERATE] LLM answers using both its knowledge + your documents
       │
       ▼
  Grounded Answer (based on real, current data)
```

**On-device RAG advantage:** Documents never leave the phone. Perfect for personal notes, medical records, private documents.

---

## 2. The RAG Pipeline Architecture

```
INDEXING (one-time, when documents are added):
  Document Text
       │
       ▼
  Text Chunker (split into 200–500 token chunks)
       │
       ▼
  Embedding Model (text → 384-dim vector)
       │
       ▼
  Vector Store (in-memory or SQLite)

QUERYING (every user question):
  User Question
       │
       ▼
  Embedding Model (question → vector)
       │
       ▼
  Cosine Similarity Search (find top-K most similar chunks)
       │
       ▼
  Retrieved Chunks (top 3–5 most relevant)
       │
       ▼
  Augmented Prompt = System + Context + Question
       │
       ▼
  Gemma/Phi-3 Inference → Answer
```

## 3. Embedding Model Setup

We use `all-MiniLM-L6-v2` converted to TFLite — a small (22 MB) but powerful embedding model:

### Python Export

```python
# export_embedding_model.py
# pip install sentence-transformers tensorflow

from sentence_transformers import SentenceTransformer
import tensorflow as tf
import numpy as np

# Load MiniLM embedding model (22 MB, 384-dim embeddings)
model = SentenceTransformer('sentence-transformers/all-MiniLM-L6-v2')

# Export to TFLite
def create_tflite_embedder(model, max_seq_len=128):
    """Wrap sentence transformer encoder for TFLite export."""

    @tf.function(input_signature=[
        tf.TensorSpec(shape=[1, max_seq_len], dtype=tf.int32, name="input_ids"),
        tf.TensorSpec(shape=[1, max_seq_len], dtype=tf.int32, name="attention_mask"),
    ])
    def encode(input_ids, attention_mask):
        outputs = model[0].auto_model(
            input_ids=input_ids,
            attention_mask=attention_mask
        )
        # Mean pooling
        token_embeddings = outputs.last_hidden_state
        mask = tf.cast(tf.expand_dims(attention_mask, -1), tf.float32)
        pooled = tf.reduce_sum(token_embeddings * mask, axis=1)
        pooled = pooled / tf.reduce_sum(mask, axis=1)
        # L2 normalize
        return tf.nn.l2_normalize(pooled, axis=-1)

    converter = tf.lite.TFLiteConverter.from_concrete_functions(
        [encode.get_concrete_function()]
    )
    converter.optimizations = [tf.lite.Optimize.DEFAULT]
    tflite_model = converter.convert()

    with open("minilm_embedder.tflite", "wb") as f:
        f.write(tflite_model)

    print(f"Exported: {len(tflite_model)/1e6:.1f} MB")
    print(f"Embedding dim: 384")

create_tflite_embedder(model)
```

Copy to assets:

## 4. TextEmbedder.kt

```kotlin
// TextEmbedder.kt
package com.yourname.chatapp.rag

import android.content.Context
import android.util.Log
import org.tensorflow.lite.Interpreter
import org.tensorflow.lite.support.common.FileUtil
import java.nio.ByteBuffer
import java.nio.ByteOrder
import kotlin.math.sqrt

class TextEmbedder(context: Context) {

    companion object {
        private const val TAG        = "TextEmbedder"
        private const val MODEL_FILE = "minilm_embedder.tflite"
        private const val VOCAB_FILE = "minilm_vocab.txt"
        private const val MAX_LEN    = 128
        private const val EMBED_DIM  = 384
    }

    private val interpreter: Interpreter
    private val tokenizer: WordPieceTokenizer

    init {
        val options = Interpreter.Options().setNumThreads(4)
        interpreter = Interpreter(FileUtil.loadMappedFile(context, MODEL_FILE), options)
        tokenizer   = WordPieceTokenizer(context, VOCAB_FILE)
        Log.d(TAG, "TextEmbedder ready — dim=$EMBED_DIM")
    }

    /**
     * Embed a text string into a 384-dimensional float vector.
     * The vector is L2-normalized (unit length).
     */
    fun embed(text: String): FloatArray {
        val tokenized = tokenizer.tokenize(text.take(512), MAX_LEN)

        val inputIdsBuf = intArrayToByteBuffer(tokenized.inputIds)
        val maskBuf     = intArrayToByteBuffer(tokenized.attentionMask)

        val outputBuf = ByteBuffer
            .allocateDirect(1 * EMBED_DIM * 4)
            .order(ByteOrder.nativeOrder())

        interpreter.runForMultipleInputsOutputs(
            arrayOf(inputIdsBuf, maskBuf),
            mapOf(0 to outputBuf)
        )

        outputBuf.rewind()
        val embedding = FloatArray(EMBED_DIM)
        outputBuf.asFloatBuffer().get(embedding)

        return embedding
    }

    /**
     * Embed multiple texts in batch.
     * More efficient than calling embed() in a loop for many documents.
     */
    fun embedBatch(texts: List<String>): List<FloatArray> {
        return texts.map { embed(it) }
    }

    /**
     * Cosine similarity between two L2-normalized embeddings.
     * Since vectors are unit-length, cosine sim = dot product.
     * Returns value in [-1, 1] — higher = more similar.
     */
    fun cosineSimilarity(a: FloatArray, b: FloatArray): Float {
        require(a.size == b.size) { "Embedding dimensions must match" }
        return a.zip(b.toList()).sumOf { (ai, bi) -> (ai * bi).toDouble() }.toFloat()
    }

    private fun intArrayToByteBuffer(array: IntArray): ByteBuffer {
        val buf = ByteBuffer.allocateDirect(array.size * 4).order(ByteOrder.nativeOrder())
        array.forEach { buf.putInt(it) }
        buf.rewind()
        return buf
    }

    fun close() = interpreter.close()
}
```

## 5. VectorStore.kt — In-Memory Document Store

```kotlin
// VectorStore.kt
package com.yourname.chatapp.rag

import android.util.Log
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext

data class Document(
    val id: String,
    val content: String,           // the original text chunk
    val embedding: FloatArray,     // 384-dim embedding vector
    val metadata: Map<String, String> = emptyMap()  // source, title, page, etc.
)

data class SearchResult(
    val document: Document,
    val similarity: Float          // cosine similarity score [0, 1]
)

class VectorStore {

    companion object {
        private const val TAG = "VectorStore"
    }

    private val documents = mutableListOf<Document>()

    /**
     * Add a document with its pre-computed embedding.
     */
    fun addDocument(doc: Document) {
        documents.add(doc)
        Log.d(TAG, "Added doc '${doc.id}' — total: ${documents.size}")
    }

    /**
     * Add multiple documents at once.
     */
    fun addDocuments(docs: List<Document>) {
        documents.addAll(docs)
        Log.d(TAG, "Added ${docs.size} docs — total: ${documents.size}")
    }

    /**
     * Find the top-K most similar documents to the query embedding.
     * Uses brute-force cosine similarity — fast enough for < 10,000 docs.
     */
    suspend fun search(
        queryEmbedding: FloatArray,
        topK: Int = 5,
        minSimilarity: Float = 0.3f
    ): List<SearchResult> = withContext(Dispatchers.Default) {

        if (documents.isEmpty()) return@withContext emptyList()

        documents
            .map { doc ->
                val sim = cosineSimilarity(queryEmbedding, doc.embedding)
                SearchResult(doc, sim)
            }
            .filter { it.similarity >= minSimilarity }
            .sortedByDescending { it.similarity }
            .take(topK)
    }

    private fun cosineSimilarity(a: FloatArray, b: FloatArray): Float {
        var dot = 0f
        var normA = 0f
        var normB = 0f
        for (i in a.indices) {
            dot  += a[i] * b[i]
            normA += a[i] * a[i]
            normB += b[i] * b[i]
        }
        val denom = kotlin.math.sqrt(normA * normB)
        return if (denom == 0f) 0f else dot / denom
    }

    /**
     * Remove a document by ID.
     */
    fun removeDocument(id: String) {
        documents.removeAll { it.id == id }
    }

    /**
     * Clear all documents from the store.
     */
    fun clear() {
        documents.clear()
        Log.d(TAG, "Vector store cleared")
    }

    val size: Int get() = documents.size

    val isEmpty: Boolean get() = documents.isEmpty()
}
```

## 6. TextChunker.kt — Split Documents into Chunks

```kotlin
// TextChunker.kt
package com.yourname.chatapp.rag

/**
 * Splits long text into overlapping chunks for better retrieval.
 *
 * Overlapping chunks ensure that context at chunk boundaries
 * isn't lost — the end of chunk N appears at the start of chunk N+1.
 */
object TextChunker {

    /**
     * Split text into chunks of [chunkSize] words with [overlapWords] overlap.
     *
     * @param text         Raw document text
     * @param chunkSize    Target chunk size in words (default 100)
     * @param overlapWords Words shared between adjacent chunks (default 20)
     * @return List of text chunks
     */
    fun chunk(
        text: String,
        chunkSize: Int = 100,
        overlapWords: Int = 20
    ): List<String> {
        val words = text
            .replace(Regex("\\s+"), " ")
            .trim()
            .split(" ")
            .filter { it.isNotBlank() }

        if (words.size <= chunkSize) return listOf(text.trim())

        val chunks = mutableListOf<String>()
        var start = 0

        while (start < words.size) {
            val end = minOf(start + chunkSize, words.size)
            chunks.add(words.subList(start, end).joinToString(" "))
            start += chunkSize - overlapWords
        }

        return chunks
    }

    /**
     * Split text by paragraph boundaries — preserves natural structure.
     * Falls back to word chunking for very long paragraphs.
     */
    fun chunkByParagraph(
        text: String,
        maxChunkWords: Int = 200
    ): List<String> {
        val paragraphs = text
            .split(Regex("\\n{2,}"))
            .map { it.trim() }
            .filter { it.isNotBlank() }

        val chunks = mutableListOf<String>()
        val currentChunk = StringBuilder()
        var currentWordCount = 0

        for (para in paragraphs) {
            val paraWords = para.split(" ").size

            if (currentWordCount + paraWords > maxChunkWords && currentChunk.isNotEmpty()) {
                chunks.add(currentChunk.toString().trim())
                currentChunk.clear()
                currentWordCount = 0
            }

            if (currentChunk.isNotEmpty()) currentChunk.append("\n\n")
            currentChunk.append(para)
            currentWordCount += paraWords
        }

        if (currentChunk.isNotEmpty()) chunks.add(currentChunk.toString().trim())

        return chunks
    }
}
```

## 7. RagPipeline.kt — The Complete Pipeline

```kotlin
// RagPipeline.kt
package com.yourname.chatapp.rag

import android.content.Context
import android.util.Log
import com.yourname.chatapp.GemmaInferenceHelper
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.withContext

data class RagResult(
    val answer: Flow<String>,          // streaming answer
    val retrievedDocs: List<SearchResult>,  // what was retrieved
    val augmentedPrompt: String        // the full prompt sent to LLM
)

class RagPipeline(
    private val context: Context,
    private val llmEngine: GemmaInferenceHelper,
    private val topK: Int = 3,
    private val minSimilarity: Float = 0.25f
) {
    companion object {
        private const val TAG = "RagPipeline"
        private const val MAX_CONTEXT_CHARS = 2000   // stay within LLM context window
    }

    val embedder    = TextEmbedder(context)
    val vectorStore = VectorStore()

    /**
     * Index a document — chunk it, embed each chunk, store in vector store.
     * Call this for each document you want the LLM to know about.
     */
    suspend fun indexDocument(
        docId: String,
        text: String,
        metadata: Map<String, String> = emptyMap()
    ) = withContext(Dispatchers.IO) {

        val chunks = TextChunker.chunkByParagraph(text, maxChunkWords = 150)
        Log.d(TAG, "Indexing '$docId': ${chunks.size} chunks")

        chunks.forEachIndexed { i, chunk ->
            val embedding = embedder.embed(chunk)
            val doc = Document(
                id        = "${docId}_chunk_$i",
                content   = chunk,
                embedding = embedding,
                metadata  = metadata + mapOf("chunk_index" to i.toString())
            )
            vectorStore.addDocument(doc)
        }

        Log.d(TAG, "Indexed '$docId' — vector store size: ${vectorStore.size}")
    }

    /**
     * Answer a question using RAG:
     * 1. Embed the question
     * 2. Retrieve relevant document chunks
     * 3. Build augmented prompt
     * 4. Stream LLM response
     */
    suspend fun query(question: String): RagResult = withContext(Dispatchers.IO) {

        // Step 1: Embed the question
        val questionEmbedding = embedder.embed(question)
        Log.d(TAG, "Question embedded")

        // Step 2: Retrieve relevant chunks
        val retrieved = vectorStore.search(questionEmbedding, topK, minSimilarity)
        Log.d(TAG, "Retrieved ${retrieved.size} chunks (min sim=$minSimilarity)")

        retrieved.forEachIndexed { i, r ->
            Log.d(TAG, "  [$i] sim=${"%.3f".format(r.similarity)} — '${r.document.content.take(60)}'")
        }

        // Step 3: Build augmented prompt
        val contextText = buildContext(retrieved)
        val augmentedPrompt = buildAugmentedPrompt(question, contextText, retrieved.isEmpty())

        Log.d(TAG, "Augmented prompt length: ${augmentedPrompt.length} chars")

        // Step 4: Stream LLM response
        val answerFlow = llmEngine.generateResponseStream(augmentedPrompt)

        RagResult(
            answer         = answerFlow,
            retrievedDocs  = retrieved,
            augmentedPrompt = augmentedPrompt
        )
    }

    private fun buildContext(results: List<SearchResult>): String {
        val sb = StringBuilder()
        var totalChars = 0

        for ((i, result) in results.withIndex()) {
            val chunk = result.document.content
            val source = result.document.metadata["source"] ?: "Document ${i + 1}"

            if (totalChars + chunk.length > MAX_CONTEXT_CHARS) break

            sb.append("--- $source (relevance: ${"%.0f".format(result.similarity * 100)}%) ---\n")
            sb.append(chunk)
            sb.append("\n\n")
            totalChars += chunk.length
        }

        return sb.toString().trim()
    }

    private fun buildAugmentedPrompt(
        question: String,
        context: String,
        noContextFound: Boolean
    ): String {
        return if (noContextFound) {
            // No relevant documents found — answer from model knowledge only
            """Answer this question based on your knowledge.
Be honest if you don't know the answer.

Question: $question"""
        } else {
            // Augment with retrieved context
            """You are a helpful assistant. Answer the question using ONLY the provided context.
If the context doesn't contain enough information, say so clearly.
Do not make up information not present in the context.

Context:
$context

Question: $question

Answer:"""
        }
    }

    /**
     * Index all voice notes from the database as documents.
     * Lets users ask questions about their own notes.
     */
    suspend fun indexVoiceNotes(notes: List<Pair<String, String>>) {
        // notes = List of (noteId, transcript)
        notes.forEach { (id, transcript) ->
            indexDocument(
                docId    = "note_$id",
                text     = transcript,
                metadata = mapOf("source" to "Voice Note", "note_id" to id)
            )
        }
        Log.d(TAG, "Indexed ${notes.size} voice notes")
    }

    fun close() {
        embedder.close()
        vectorStore.clear()
    }
}
```

## 8. Usage — Index and Query

```kotlin
// In your ViewModel
class RagViewModel(application: Application) : AndroidViewModel(application) {

    private val llmEngine = GemmaInferenceHelper(
        context   = application,
        modelPath = "${application.filesDir}/gemma-2b-it-gpu-int4.bin"
    )

    private val ragPipeline = RagPipeline(
        context   = application,
        llmEngine = llmEngine,
        topK      = 3
    )

    private val _answer = MutableStateFlow("")
    val answer = _answer.asStateFlow()

    fun initializeAndIndex() {
        viewModelScope.launch(Dispatchers.IO) {
            // Initialize LLM
            llmEngine.initialize()

            // Index sample documents
            ragPipeline.indexDocument(
                docId = "android_guide",
                text  = """
                    CameraX is a Jetpack library that makes camera development easier.
                    It works consistently across Android 5.0+ devices.
                    CameraX has three use cases: Preview, ImageCapture, and ImageAnalysis.
                    ImageAnalysis is used for real-time AI inference on camera frames.
                    Always use STRATEGY_KEEP_ONLY_LATEST to avoid frame queue buildup.
                """.trimIndent(),
                metadata = mapOf("source" to "Android Camera Guide")
            )

            ragPipeline.indexDocument(
                docId = "ml_overview",
                text  = """
                    On-device AI runs machine learning models directly on user hardware.
                    TFLite is Google's runtime for mobile inference.
                    ONNX Runtime supports models from PyTorch and other frameworks.
                    MediaPipe provides ready-made solutions for face, pose, and object detection.
                    ML Kit offers offline OCR, translation, and language identification.
                """.trimIndent(),
                metadata = mapOf("source" to "ML Overview")
            )
        }
    }

    fun askQuestion(question: String) {
        viewModelScope.launch {
            _answer.value = ""

            val result = ragPipeline.query(question)

            // Log what was retrieved
            result.retrievedDocs.forEach { r ->
                Log.d("RAG", "Retrieved: '${r.document.content.take(50)}' (${r.similarity})")
            }

            // Stream the answer
            result.answer.collect { token ->
                _answer.value += token
            }
        }
    }

    override fun onCleared() {
        super.onCleared()
        ragPipeline.close()
        llmEngine.close()
    }
}

// Example queries and expected behavior:
// "What is CameraX?"     → retrieves android_guide chunk → answers from context
// "How does TFLite work?"→ retrieves ml_overview chunk → answers from context
// "Who is the president?"→ no relevant doc found → answers from model knowledge
```

## 10. Performance Reference

| Operation | Time |
|---|---|
| Embed one chunk (22MB MiniLM) | ~20–40ms |
| Index 100 document chunks | ~3–5 seconds |
| Vector search (1000 docs) | ~5ms |
| Vector search (10,000 docs) | ~50ms |
| Full RAG query (retrieve + generate) | ~500ms + LLM streaming |

> 💡 For apps with > 10,000 document chunks, replace brute-force search with an approximate nearest-neighbor library like `hnswlib` via JNI.

## 11. Summary

- RAG = Retrieve relevant chunks → Augment prompt → Generate grounded answer
- Use `all-MiniLM-L6-v2` TFLite — only 22 MB, produces high-quality 384-dim embeddings
- `TextChunker.chunkByParagraph()` preserves document structure better than fixed-size chunking
- Always log retrieved chunks and similarity scores during development
- Set `minSimilarity = 0.25f` — lower accepts more (recall ↑, precision ↓)
- Tell the LLM to answer ONLY from context and admit when it doesn't know
