## 1. How the GPU Delegate Works

```
Without GPU Delegate:
  Model → TFLite CPU Runtime → ARM NEON SIMD → Result
  All math runs on CPU cores sequentially

With GPU Delegate:
  Model → GPU Delegate → OpenGL ES Compute Shaders → Adreno/Mali GPU → Result
  Thousands of GPU shader cores execute matrix math in massive parallel
  
Why GPUs are faster for AI:
  Conv2D on a 224×224 image = millions of multiply-add operations
  CPU: executes these sequentially (even with SIMD: 8 at a time)
  GPU: executes thousands simultaneously (Adreno 750: 3072 cores)
  
Typical speedup: 3–8× over CPU for vision models
```

## 3. Basic GPU Delegate Setup

```kotlin
// GpuDelegateManager.kt
package com.yourname.vision

import android.content.Context
import android.util.Log
import org.tensorflow.lite.Interpreter
import org.tensorflow.lite.gpu.CompatibilityList
import org.tensorflow.lite.gpu.GpuDelegate
import org.tensorflow.lite.gpu.GpuDelegateFactory
import org.tensorflow.lite.support.common.FileUtil

class GpuDelegateManager(private val context: Context) {

    companion object {
        private const val TAG = "GpuDelegate"
    }

    /**
     * Check if GPU delegate is compatible with this device.
     * Always check before creating GpuDelegate — avoids crashes on unsupported devices.
     */
    fun isGpuCompatible(): Boolean {
        val compatList = CompatibilityList()
        val isCompatible = compatList.isDelegateSupportedOnThisDevice
        Log.d(TAG, "GPU compatible: $isCompatible")
        return isCompatible
    }

    /**
     * Create a GPU-accelerated TFLite Interpreter.
     * Falls back to CPU if GPU is not compatible or initialization fails.
     *
     * @param modelFileName  Asset file name (e.g. "yolov8n.tflite")
     * @param useGpu         Whether to attempt GPU delegation
     * @param inferenceMode  SINGLE_ANSWER for photos, SUSTAINED_SPEED for video
     * @return Pair of (Interpreter, isUsingGpu)
     */
    fun createInterpreter(
        modelFileName: String,
        useGpu: Boolean = true,
        inferenceMode: InferenceMode = InferenceMode.SINGLE_ANSWER
    ): Pair<Interpreter, Boolean> {

        val modelBuffer = FileUtil.loadMappedFile(context, modelFileName)

        if (useGpu && isGpuCompatible()) {
            try {
                val gpuDelegate = buildGpuDelegate(inferenceMode)
                val options = Interpreter.Options()
                    .addDelegate(gpuDelegate)

                val interpreter = Interpreter(modelBuffer, options)
                Log.d(TAG, "✅ GPU Delegate active")
                return interpreter to true

            } catch (e: Exception) {
                Log.w(TAG, "GPU delegate failed (${e.message}) — falling back to CPU")
            }
        }

        // CPU fallback
        val options = Interpreter.Options().apply {
            setNumThreads(4)
            setUseXNNPACK(true)
        }
        Log.d(TAG, "Using CPU inference")
        return Interpreter(modelBuffer, options) to false
    }

    enum class InferenceMode { SINGLE_ANSWER, SUSTAINED_SPEED }

    private fun buildGpuDelegate(mode: InferenceMode): GpuDelegate {
        val options = GpuDelegate.Options().apply {

            // Allow FP16 precision — ~1.5× faster on most GPUs
            // Tiny accuracy loss (< 0.1% on most models) — worth it
            setPrecisionLossAllowed(true)

            // Allow quantized INT8 models to run on GPU
            // Not all GPUs support this — falls back gracefully
            setQuantizedModelsAllowed(true)

            // Inference preference
            setInferencePreference(
                when (mode) {
                    InferenceMode.SINGLE_ANSWER ->
                        // GPU boosts to max freq for fastest single result
                        GpuDelegate.Options.INFERENCE_PREFERENCE_FAST_SINGLE_ANSWER

                    InferenceMode.SUSTAINED_SPEED ->
                        // GPU runs at stable freq — prevents thermal throttling in video
                        GpuDelegate.Options.INFERENCE_PREFERENCE_SUSTAINED_SPEED
                }
            )
        }
        return GpuDelegate(options)
    }
}
```

## 4. GPU Delegate with Shader Serialization

The first inference compiles OpenGL ES shaders — takes 200–500ms. Cache them:

```kotlin
// GpuDelegateWithCache.kt
package com.yourname.vision

import android.content.Context
import android.util.Log
import org.tensorflow.lite.Interpreter
import org.tensorflow.lite.gpu.GpuDelegate
import org.tensorflow.lite.support.common.FileUtil
import java.io.File

class GpuDelegateWithCache(private val context: Context) {

    companion object {
        private const val TAG        = "GpuCache"
        private const val CACHE_DIR  = "gpu_shader_cache"
    }

    /**
     * Create GPU delegate with shader serialization.
     *
     * First run: compiles shaders → saves to disk → ~500ms
     * Subsequent runs: loads cached shaders → ~50ms
     *
     * @param modelToken  Unique string per model version (e.g. "yolov8n_v2")
     *                    Change this whenever the model file changes!
     */
    fun createInterpreterWithCache(
        modelFileName: String,
        modelToken: String
    ): Interpreter {

        val modelBuffer   = FileUtil.loadMappedFile(context, modelFileName)
        val cacheDir      = File(context.cacheDir, CACHE_DIR).apply { mkdirs() }
        val shaderCache   = File(cacheDir, "${modelToken}_shaders.bin")
        val cacheExists   = shaderCache.exists() && shaderCache.length() > 0

        Log.d(TAG, "Shader cache: ${if (cacheExists) "HIT" else "MISS"} — $shaderCache")

        val gpuOptions = GpuDelegate.Options().apply {
            setPrecisionLossAllowed(true)
            setSerializationParams(
                shaderCache.absolutePath,    // path to save/load compiled shaders
                modelToken                   // cache key — must change with model version
            )
        }

        return try {
            val delegate    = GpuDelegate(gpuOptions)
            val options     = Interpreter.Options().addDelegate(delegate)
            val interpreter = Interpreter(modelBuffer, options)

            Log.d(TAG, "GPU interpreter created ${if (cacheExists) "(cached shaders)" else "(compiling shaders)"}")
            interpreter

        } catch (e: Exception) {
            Log.w(TAG, "GPU with cache failed: ${e.message} — using CPU")
            Interpreter(modelBuffer, Interpreter.Options().apply {
                setNumThreads(4)
                setUseXNNPACK(true)
            })
        }
    }

    /**
     * Clear cached shaders (call when model is updated).
     */
    fun clearCache(modelToken: String) {
        val cacheDir = File(context.cacheDir, CACHE_DIR)
        File(cacheDir, "${modelToken}_shaders.bin").delete()
        Log.d(TAG, "Cleared GPU shader cache for $modelToken")
    }
}
```

## 5. GPU Delegate Lifecycle — Critical Rules

```kotlin
// DelegateLifecycleExample.kt

class VisionClassifier(context: Context) {

    // ✅ Declare delegate as a field — must stay alive as long as interpreter
    private var gpuDelegate: GpuDelegate? = null
    private val interpreter: Interpreter

    init {
        // ✅ Create delegate BEFORE interpreter
        gpuDelegate = GpuDelegate(GpuDelegate.Options().setPrecisionLossAllowed(true))

        val options = Interpreter.Options().addDelegate(gpuDelegate!!)
        val model   = FileUtil.loadMappedFile(context, "model.tflite")
        interpreter = Interpreter(model, options)
    }

    fun classify(bitmap: Bitmap): FloatArray {
        // Run inference — GPU delegate handles everything automatically
        val input  = preprocessBitmap(bitmap)
        val output = Array(1) { FloatArray(1000) }
        interpreter.run(input, output)
        return output[0]
    }

    // ✅ ALWAYS close BOTH interpreter AND delegate
    // ✅ Close interpreter FIRST, then delegate
    fun close() {
        interpreter.close()   // ← must close first
        gpuDelegate?.close()  // ← then delegate (frees GPU memory)
        gpuDelegate = null
    }
}

// ❌ WRONG — causes GPU memory leak:
// interpreter.close()   // forgot gpuDelegate.close()

// ❌ WRONG — causes crash:
// gpuDelegate.close()   // closed delegate before interpreter
// interpreter.close()
```

## 6. GPU Delegate with TFLite Support Library (Easier)

The `GpuDelegateFactory` auto-configures based on device:

```kotlin
import org.tensorflow.lite.gpu.GpuDelegateFactory

// Simplest approach — let TFLite decide optimal GPU settings
fun createOptimizedInterpreter(context: Context, modelFile: String): Interpreter {
    val model = FileUtil.loadMappedFile(context, modelFile)

    val options = Interpreter.Options().apply {
        // GpuDelegateFactory auto-picks best GPU settings for this device
        val gpuOptions = GpuDelegateFactory.Options().apply {
            setForceBackend(GpuDelegateFactory.Options.GpuBackend.OPENGL)
            setPrecisionLossAllowed(true)
        }
        addDelegateFactory(GpuDelegateFactory(gpuOptions))
        // Auto-falls back to CPU if GPU not supported — no try-catch needed
    }

    return Interpreter(model, options)
}
```

## 7. GPU Delegate for Real-Time Camera (CameraX)

```kotlin
// RealTimeGpuClassifier.kt
class RealTimeGpuClassifier(context: Context) : ImageAnalysis.Analyzer {

    // Pre-allocate — never allocate inside analyze()
    private val gpuDelegate = GpuDelegate(
        GpuDelegate.Options()
            .setPrecisionLossAllowed(true)
            .setInferencePreference(
                GpuDelegate.Options.INFERENCE_PREFERENCE_SUSTAINED_SPEED  // ← for video
            )
    )
    private val interpreter: Interpreter
    private val inputBuffer:  ByteBuffer
    private val outputBuffer: TensorBuffer

    init {
        val model   = FileUtil.loadMappedFile(context, "yolov8n.tflite")
        val options = Interpreter.Options().addDelegate(gpuDelegate)
        interpreter = Interpreter(model, options)

        // Pre-allocate buffers (do this once, reuse every frame)
        val inputShape  = interpreter.getInputTensor(0).shape()   // [1, 320, 320, 3]
        val outputShape = interpreter.getOutputTensor(0).shape()  // [1, 84, 2100]
        val outputType  = interpreter.getOutputTensor(0).dataType()

        inputBuffer  = ByteBuffer.allocateDirect(
            inputShape[1] * inputShape[2] * inputShape[3] * 4
        ).order(ByteOrder.nativeOrder())

        outputBuffer = TensorBuffer.createFixedSize(outputShape, outputType)
    }

    override fun analyze(imageProxy: ImageProxy) {
        try {
            val bitmap = imageProxy.toBitmap()

            // Fill input buffer (reuse — no allocation)
            fillInputBuffer(bitmap)

            // Run GPU inference
            interpreter.run(inputBuffer, outputBuffer.buffer.rewind())

            // Process output
            val results = decodeOutput(outputBuffer.floatArray)
            onResults(results)

        } finally {
            imageProxy.close()
        }
    }

    private fun fillInputBuffer(bitmap: Bitmap) {
        val scaled = Bitmap.createScaledBitmap(bitmap, 320, 320, true)
        inputBuffer.rewind()
        val pixels = IntArray(320 * 320)
        scaled.getPixels(pixels, 0, 320, 0, 0, 320, 320)
        for (pixel in pixels) {
            inputBuffer.putFloat(((pixel shr 16) and 0xFF) / 255.0f)
            inputBuffer.putFloat(((pixel shr 8)  and 0xFF) / 255.0f)
            inputBuffer.putFloat((pixel          and 0xFF) / 255.0f)
        }
        inputBuffer.rewind()
    }

    private fun decodeOutput(data: FloatArray): List<Any> = emptyList() // your decode logic

    private fun onResults(results: List<Any>) {}  // your result handler

    fun close() {
        interpreter.close()
        gpuDelegate.close()
    }
}
```

## 8. GPU-Compatible Model Checklist

Not all models run well on the GPU Delegate:

```
✅ GPU-friendly models:
  Standard CNNs: MobileNet, EfficientNet, ResNet
  YOLO variants (v5, v7, v8 nano/small)
  SSD object detectors
  FP32 and FP16 models
  Fixed input shape models

⚠️ May have partial GPU support:
  INT8 quantized models (depends on GPU driver version)
  Models with batch normalization (usually fine)
  Models with Resize operations (GPU supports bilinear)

❌ GPU-unfriendly (will fall back to CPU):
  Custom TFLite ops (not in standard op set)
  Models with control flow (if/while loops)
  Dynamic input shapes (some ops unsupported)
  Models using tf.while_loop
  Very small models (overhead > benefit)
```

## 10. Common GPU Delegate Errors

| Error | Cause | Fix |
|---|---|---|
| `GpuDelegateException: GPU delegate failed` | GPU not compatible | Check `CompatibilityList.isDelegateSupportedOnThisDevice` first |
| `libOpenCL.so conflicts` | Multiple OpenCL libs | Add `pickFirsts += "**/libOpenCL.so"` in packaging |
| Slow first inference (~500ms) | Shader compilation | Enable shader serialization (Section 4) |
| Wrong output values | Model uses unsupported op on GPU | Check Logcat for ops falling to CPU |
| App crash on delegate.close() | Closed before interpreter | Always close interpreter FIRST, then delegate |
| OOM on GPU | Model too large for GPU memory | Use smaller model or reduce batch size |

## 11. Summary

- GPU Delegate routes model ops to Adreno/Mali GPU via OpenGL ES compute shaders
- `setPrecisionLossAllowed(true)` enables FP16 — ~1.5× faster with negligible accuracy loss
- Use `SUSTAINED_SPEED` for video (prevents thermal throttle), `FAST_SINGLE_ANSWER` for photos
- Always check `CompatibilityList.isDelegateSupportedOnThisDevice` before creating delegate
- Enable shader serialization — eliminates 200–500ms cold start on every subsequent run
- Close interpreter FIRST, then delegate — never the other way around
- Pre-allocate `ByteBuffer` and `TensorBuffer` once — never inside the inference loop
