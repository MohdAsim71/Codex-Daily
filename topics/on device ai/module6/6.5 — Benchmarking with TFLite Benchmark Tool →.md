## 1. TFLite Benchmark Tool — Why Use It?

```
Two ways to benchmark TFLite models:

1. TFLite Benchmark Tool (adb)
   ✅ Official Google tool — most accurate
   ✅ Tests pure inference time (no app overhead)
   ✅ Tests all delegates: CPU, GPU, NNAPI, Hexagon
   ✅ Detailed memory breakdown
   ❌ Requires adb connection (development only)

2. In-App Benchmark (Kotlin)
   ✅ Runs on users' real devices in production
   ✅ Captures real-world conditions (thermal, memory pressure)
   ✅ Can run as part of CI/CD
   ❌ Includes some app overhead
   ❌ Need to ship benchmark code

Use both: TFLite tool for development, in-app for production monitoring.
```

## 3. Run Benchmarks via ADB

### CPU Benchmark

```bash
adb shell /data/local/tmp/benchmark_model \
  --graph=/data/local/tmp/yolov8n.tflite \
  --num_threads=4 \
  --num_runs=50 \
  --warmup_runs=5 \
  --report_inference_type=float

# Output:
# Loaded model /data/local/tmp/yolov8n.tflite
# The input(s) for model execution are randomly generated.
# Average inference timings in us: Warm-up runs: 95234, Regular runs: 88421
# CPU(wall clock) time: avg=88.42ms, std=2.14ms, min=84.11ms, max=96.33ms
```

### GPU Delegate Benchmark

```bash
adb shell /data/local/tmp/benchmark_model \
  --graph=/data/local/tmp/yolov8n.tflite \
  --use_gpu=true \
  --gpu_precision_loss_allowed=true \
  --num_runs=50 \
  --warmup_runs=10

# Output:
# Loaded model yolov8n.tflite
# Initialized GPU delegate
# Average inference timings: avg=17.82ms, std=0.94ms, min=16.11ms, max=21.43ms
```

### NNAPI Benchmark

```bash
adb shell /data/local/tmp/benchmark_model \
  --graph=/data/local/tmp/yolov8n.tflite \
  --use_nnapi=true \
  --nnapi_execution_preference=fast_single_answer \
  --num_runs=50 \
  --warmup_runs=10

# Output:
# Loaded model yolov8n.tflite
# Using NNAPI delegate
# Average inference timings: avg=9.14ms, std=0.42ms, min=8.73ms, max=10.21ms
```

### All Three in One Script

```bash
#!/bin/bash
# benchmark_all.sh — push and benchmark on connected device

MODEL="yolov8n.tflite"
BINARY="benchmark_model"
REMOTE_DIR="/data/local/tmp"
RUNS=50

echo "Pushing files..."
adb push $MODEL $REMOTE_DIR/
adb push $BINARY $REMOTE_DIR/
adb shell chmod +x $REMOTE_DIR/$BINARY

echo ""
echo "=== CPU (4 threads) ==="
adb shell $REMOTE_DIR/$BINARY \
  --graph=$REMOTE_DIR/$MODEL \
  --num_threads=4 \
  --num_runs=$RUNS \
  --warmup_runs=5 2>&1 | grep "Average inference"

echo ""
echo "=== GPU Delegate ==="
adb shell $REMOTE_DIR/$BINARY \
  --graph=$REMOTE_DIR/$MODEL \
  --use_gpu=true \
  --gpu_precision_loss_allowed=true \
  --num_runs=$RUNS \
  --warmup_runs=10 2>&1 | grep "Average inference"

echo ""
echo "=== NNAPI Delegate ==="
adb shell $REMOTE_DIR/$BINARY \
  --graph=$REMOTE_DIR/$MODEL \
  --use_nnapi=true \
  --num_runs=$RUNS \
  --warmup_runs=10 2>&1 | grep "Average inference"

echo ""
echo "Done. Check results above."
```

## 5. In-App Benchmark Runner

A production-ready in-app benchmark that users can trigger:

```kotlin
// InAppBenchmarkRunner.kt
package com.yourname.benchmark

import android.content.Context
import android.os.Build
import android.os.SystemClock
import android.util.Log
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import org.tensorflow.lite.Interpreter
import org.tensorflow.lite.gpu.CompatibilityList
import org.tensorflow.lite.gpu.GpuDelegate
import org.tensorflow.lite.nnapi.NnApiDelegate
import org.tensorflow.lite.support.common.FileUtil
import java.nio.ByteBuffer
import java.nio.ByteOrder

data class BackendResult(
    val backend: String,
    val avgMs: Float,
    val minMs: Long,
    val maxMs: Long,
    val p95Ms: Long,
    val supported: Boolean,
    val errorMessage: String = ""
)

data class BenchmarkReport(
    val modelName: String,
    val deviceModel: String,
    val androidVersion: Int,
    val results: List<BackendResult>,
    val timestampMs: Long = System.currentTimeMillis()
) {
    val fastestBackend: BackendResult?
        get() = results.filter { it.supported }.minByOrNull { it.avgMs }

    fun toMarkdown(): String {
        val sb = StringBuilder()
        sb.appendLine("## Benchmark: $modelName")
        sb.appendLine("**Device:** $deviceModel (Android $androidVersion)")
        sb.appendLine()
        sb.appendLine("| Backend | Avg | Min | Max | P95 | Speedup vs CPU |")
        sb.appendLine("|---|---|---|---|---|---|")

        val cpuAvg = results.find { it.backend == "CPU" }?.avgMs ?: 1f
        results.filter { it.supported }.forEach { r ->
            val speedup = if (r.backend == "CPU") "1×"
                          else "${"%.1f".format(cpuAvg / r.avgMs)}×"
            sb.appendLine(
                "| ${r.backend} " +
                "| ${r.avgMs.toInt()}ms " +
                "| ${r.minMs}ms " +
                "| ${r.maxMs}ms " +
                "| ${r.p95Ms}ms " +
                "| $speedup |"
            )
        }

        results.filter { !it.supported }.forEach { r ->
            sb.appendLine("| ${r.backend} | ❌ Not supported | | | | |")
        }

        return sb.toString()
    }
}

class InAppBenchmarkRunner(private val context: Context) {

    companion object {
        private const val TAG         = "BenchmarkRunner"
        private const val WARMUP_RUNS = 5
        private const val TIMED_RUNS  = 20
    }

    /**
     * Run a complete benchmark across CPU, GPU, and NNAPI backends.
     * Reports progress via [onProgress] callback.
     */
    suspend fun runFullBenchmark(
        modelFileName: String,
        onProgress: (String) -> Unit = {}
    ): BenchmarkReport = withContext(Dispatchers.IO) {

        val modelBuffer = FileUtil.loadMappedFile(context, modelFileName)
        val results     = mutableListOf<BackendResult>()

        // Prepare dummy input
        val inputShape  = getInputShape(modelBuffer)
        val inputSize   = inputShape.reduce { a, b -> a * b }
        val inputBuffer = ByteBuffer
            .allocateDirect(inputSize * 4)
            .order(ByteOrder.nativeOrder())
            .apply { repeat(inputSize) { putFloat((Math.random()).toFloat()) }; rewind() }

        val outputShape = getOutputShape(modelBuffer)
        val outputSize  = outputShape.reduce { a, b -> a * b }

        // 1. CPU benchmark
        onProgress("Benchmarking CPU...")
        results.add(benchmarkBackend(
            name        = "CPU",
            modelBuffer = modelBuffer,
            inputBuffer = inputBuffer,
            outputSize  = outputSize,
            buildOptions = {
                Interpreter.Options().setNumThreads(4).setUseXNNPACK(true)
            }
        ))

        // 2. GPU benchmark
        onProgress("Benchmarking GPU...")
        val gpuResult = if (CompatibilityList().isDelegateSupportedOnThisDevice) {
            val delegate = GpuDelegate(
                GpuDelegate.Options().setPrecisionLossAllowed(true)
            )
            val result = benchmarkBackend(
                name        = "GPU (FP16)",
                modelBuffer = modelBuffer,
                inputBuffer = inputBuffer,
                outputSize  = outputSize,
                buildOptions = { Interpreter.Options().addDelegate(delegate) }
            )
            delegate.close()
            result
        } else {
            BackendResult("GPU (FP16)", 0f, 0, 0, 0, false, "GPU not compatible")
        }
        results.add(gpuResult)

        // 3. NNAPI benchmark
        onProgress("Benchmarking NNAPI...")
        val nnApiResult = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.P) {
            val delegate = NnApiDelegate(
                NnApiDelegate.Options()
                    .setAllowFp16(true)
                    .setCacheDir(context.cacheDir.absolutePath)
                    .setModelToken("${modelFileName}_benchmark")
            )
            val result = benchmarkBackend(
                name        = "NNAPI (NPU)",
                modelBuffer = modelBuffer,
                inputBuffer = inputBuffer,
                outputSize  = outputSize,
                buildOptions = { Interpreter.Options().addDelegate(delegate) }
            )
            delegate.close()
            result
        } else {
            BackendResult("NNAPI (NPU)", 0f, 0, 0, 0, false, "API < 28")
        }
        results.add(nnApiResult)

        onProgress("Benchmark complete!")

        BenchmarkReport(
            modelName      = modelFileName,
            deviceModel    = "${Build.MANUFACTURER} ${Build.MODEL}",
            androidVersion = Build.VERSION.SDK_INT,
            results        = results
        )
    }

    private fun benchmarkBackend(
        name: String,
        modelBuffer: java.nio.MappedByteBuffer,
        inputBuffer: ByteBuffer,
        outputSize: Int,
        buildOptions: () -> Interpreter.Options
    ): BackendResult {
        return try {
            val interpreter = Interpreter(modelBuffer, buildOptions())
            val outputBuffer = ByteBuffer
                .allocateDirect(outputSize * 4)
                .order(ByteOrder.nativeOrder())

            // Warmup
            repeat(WARMUP_RUNS) {
                inputBuffer.rewind()
                outputBuffer.rewind()
                interpreter.run(inputBuffer, outputBuffer)
            }

            // Timed runs
            val latencies = mutableListOf<Long>()
            repeat(TIMED_RUNS) {
                inputBuffer.rewind()
                outputBuffer.rewind()
                val start = SystemClock.elapsedRealtimeNanos()
                interpreter.run(inputBuffer, outputBuffer)
                latencies.add((SystemClock.elapsedRealtimeNanos() - start) / 1_000_000)
            }

            interpreter.close()
            latencies.sort()

            BackendResult(
                backend   = name,
                avgMs     = latencies.average().toFloat(),
                minMs     = latencies.first(),
                maxMs     = latencies.last(),
                p95Ms     = latencies[(latencies.size * 0.95).toInt()],
                supported = true
            ).also { Log.d(TAG, "$name: avg=${it.avgMs.toInt()}ms") }

        } catch (e: Exception) {
            Log.w(TAG, "$name failed: ${e.message}")
            BackendResult(name, 0f, 0, 0, 0, false, e.message ?: "Unknown error")
        }
    }

    private fun getInputShape(modelBuffer: java.nio.MappedByteBuffer): IntArray {
        val interp = Interpreter(modelBuffer)
        val shape  = interp.getInputTensor(0).shape()
        interp.close()
        return shape
    }

    private fun getOutputShape(modelBuffer: java.nio.MappedByteBuffer): IntArray {
        val interp = Interpreter(modelBuffer)
        val shape  = interp.getOutputTensor(0).shape()
        interp.close()
        return shape
    }
}
```

## 6. Benchmark UI — Show Results to Users

```kotlin
// BenchmarkActivity.kt
class BenchmarkActivity : AppCompatActivity() {

    private val runner by lazy { InAppBenchmarkRunner(this) }
    private lateinit var tvStatus:  TextView
    private lateinit var tvResults: TextView
    private lateinit var btnRun:    Button
    private lateinit var progressBar: ProgressBar

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_benchmark)

        tvStatus   = findViewById(R.id.tvStatus)
        tvResults  = findViewById(R.id.tvResults)
        btnRun     = findViewById(R.id.btnRun)
        progressBar = findViewById(R.id.progressBar)

        btnRun.setOnClickListener { runBenchmark() }
    }

    private fun runBenchmark() {
        btnRun.isEnabled = false
        progressBar.visibility = View.VISIBLE
        tvResults.text = ""

        lifecycleScope.launch {
            val report = runner.runFullBenchmark(
                modelFileName = "yolov8n.tflite",
                onProgress    = { step ->
                    tvStatus.text = step
                }
            )

            // Show results
            tvResults.text = report.toMarkdown()
            tvStatus.text  = "✅ Fastest: ${report.fastestBackend?.backend} " +
                             "(${report.fastestBackend?.avgMs?.toInt()}ms)"
            btnRun.isEnabled       = true
            progressBar.visibility = View.GONE
        }
    }
}
```

## 7. Interpreting Benchmark Results

```
Key metrics explained:

Average (avg):
  The mean inference time across all timed runs.
  Best for: comparing backends on the same device
  Watch out: outliers can skew the average

P95 (95th percentile):
  95% of runs were faster than this.
  Best for: understanding worst-case latency users experience
  If avg=20ms but P95=80ms → inconsistent → thermal throttling?

Min:
  The fastest single run — usually after warmup, before throttling
  Useful for understanding theoretical peak performance

Max:
  The slowest run — usually due to GC pause or thermal event
  High max with low avg = occasional jank

Standard Deviation (std):
  Low std = consistent (good)
  High std = variable performance (check for thermal issues)

Memory:
  Peak memory = model weights + activation buffers
  High memory = OOM risk on low-RAM devices
```

## 9. Summary

- TFLite Benchmark Tool is the gold standard for accurate model benchmarking — always use it in development
- `--enable_op_profiling=true` reveals which ops are bottlenecks within the model
- In-app `InAppBenchmarkRunner` captures real-world performance on users' devices
- Always include warmup runs (5+) — cold inference is always slower due to cache misses
- Report avg AND P95 — avg hides jank, P95 reveals it
- The benchmark shell script (`benchmark_all.sh`) lets you test all 3 backends with one command
